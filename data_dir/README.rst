Empty Data Dir
==============

This directory provides a GeoServer data directory. It lacks any layers or other aspects.  The idea is that different layers will be patched into this clean data_dir.  See https://github.com/OpenTransitTools/map_server for a system that can add new workspaces and styles, etc...

NOTE: this data_dir was based on the data_dir from GeoServer 3.0.x (Sept 15, 2026).
